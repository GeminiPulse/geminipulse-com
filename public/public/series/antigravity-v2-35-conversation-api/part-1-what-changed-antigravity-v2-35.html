Release Summary: Antigravity v2.35.0 (Nov 23, 2026)

Shipping 20 improvements and 19 fixes, Google Antigravity v2.35.0 keeps local conversation history unlimited by default (removing the legacy 500-conversation pruning ceiling), introduces a built-in Conversation Management API and conversations skill, adds Cmd+F / Ctrl+F search inside full-page HTML artifacts, upgrades Auto out-of-project read permissions, accelerates large Swarm boards with on-demand message paging, and updates the official Gemini API Marketplace plugin to v2.8.0 with Gemini 4 Neon guidance.

1. Ending the 500-Conversation Pruning Cliff

Once an operator runs daily scheduled sidecars, parallel subagent swarms, and repository triage threads, 500 local conversations vanish quickly. In earlier releases, reaching that threshold quietly pruned older local conversations—wiping architecture context and code-review trails teams assumed were saved locally.

Antigravity v2.35.0 flips local history retention to unlimited by default and treats conversations as structured, addressable objects rather than disposable chat tabs. Agents, scripts, plugins, and automations can now invoke the built-in Conversation Management API and conversations skill to create, list, inspect, rename, pin, star, archive, tag, group, and delete local Antigravity conversations.
