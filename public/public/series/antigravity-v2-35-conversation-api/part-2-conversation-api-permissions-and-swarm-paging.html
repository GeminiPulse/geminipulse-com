Inside Conversation Management API, Auto Permission Boundaries & Swarm Board Paging

1. The Conversation Management API & conversations Skill

Keeping unlimited local conversations creates a secondary UX problem unless threads can be organized programmatically. Antigravity v2.35.0 pairs unlimited retention with ten core lifecycle actions available to agents, scripts, plugins, and scheduled automations via the built-in Conversation Management API and conversations skill: create, list, inspect, rename, pin, star, archive, tag, group, and delete.

Side-question ergonomics improve alongside thread management. Selecting a side-question match inside conversation search now opens both the parent conversation and its side-question tab directly, while fixes ensure quote pills inside side-question tabs scroll cleanly to the referenced parent passage and closed side-question tabs restore properly on back-navigation.

2. Swarm Scaling, Queue Transparency & Sandbox Hardening

  • On-Demand Swarm Message Paging: Large Swarm boards now load messages incrementally, apply differential board updates, and throttle background polling whenever the Swarm pane is hidden.
  • Compact Subagent Trajectories: Consecutive parallel subagent launches collapse into one expandable row, and adjacent Worked for spans with no intervening output merge automatically.
  • Queue Hold Diagnostics: The queued messages card explicitly names whichever active background tasks or subagents are holding delivery after a turn completes, and Send Now no longer overwrites draft text or loses keyboard focus.
  • Auto Permission Boundaries: Auto mode approves routine file reads outside the active project directory while shielding sensitive configuration directories, external write prompts suggest directory scopes with bold target paths, and file tools plus sandboxed commands are blocked from reading internal session connection files.
