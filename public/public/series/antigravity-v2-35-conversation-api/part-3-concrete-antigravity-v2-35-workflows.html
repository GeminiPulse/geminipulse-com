Concrete Antigravity v2.35.0 Blueprints: Triage Automations, High-Effort Routing & Searchable Artifacts

Authored by Google Gemini 4 Argon · Thinking Effort: High · Product Development & Creative Direction: Neil S. White • Release Date: November 23, 2026 • Primary Source: Google Antigravity Changelog v2.35.0 • 4 min read

1. Three High-Leverage Workflows Enabled by v2.35.0

  • Scheduled Conversation Inbox Cleanup: Pair a recurring automation with the built-in conversations skill to inspect overnight CI or curation threads, tag incidents, star failures needing operator review, and archive clean runs automatically—without ever losing older history at 500 threads.
  • Remote SSH Multi-Repo Context Switching: Use the reordered Environment-first selector (ahead of Project and Branch) to pick an SSH Host directly, clone via submenu, and let Auto mode read shared helper repositories without per-file read prompts.
  • Searchable Full-Page HTML Audit Reports: Emit dense security, schema, or benchmark summaries as full-page HTML artifacts and press Cmd+F (Ctrl+F) to jump straight to failing checks, status codes, or model badges.

2. Runnable @google/genai v3.x Triage & HTML Artifact Blueprint

Pair Antigravity v2.35.0’s updated Gemini API Marketplace plugin v2.8.0 guidance with Gemini 4 Neon at high thinking effort (matching Antigravity’s new Orchestrator/Executor default) for planning and Gemini 4 Hydrogen for crisp HTML report formatting:

import { GoogleGenAI } from "@google/genai";

const ai = new GoogleGenAI();

const triage = await ai.interactions.create({
  model: "gemini-4-neon",
  thinking_level: "high",
  input:
    "Given local conversation metadata beyond the 500-thread mark, group all 'release-audit' runs, pin verified passing deploys, and star unresolved Swarm worker stalls.",
});

const htmlDigest = await ai.interactions.create({
  model: "gemini-4-hydrogen",
  previous_interaction_id: triage.id,
  input:
    "Render the grouped triage table as a single-file HTML artifact structured for instant Cmd+F keyword navigation.",
});

console.log(htmlDigest.output_text);

3. Checklist Before Upgrading Team Defaults

  • Check Settings > Models: Orchestrator and Executor now default to High thinking effort rather than Extra High (xhigh); escalate manually on security or mathematical audits where latency is secondary.
  • Check Settings > Shortcuts: Cmd+U (Ctrl+U) is unbound by default in v2.35.0; assign a custom shortcut if your workflow opens Automations via hotkey.
  • Update the Gemini API Marketplace plugin to v2.8.0 to keep workspace gemini-4-neon and Interactions API references current.
