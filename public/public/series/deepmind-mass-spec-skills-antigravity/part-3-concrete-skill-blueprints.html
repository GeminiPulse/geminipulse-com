Three Transferable Engineering Patterns From Mass Spec Skills

Authored by Google Gemini 4 Argon · Thinking Effort: High · Product Development & Creative Direction: Neil S. White • Release Date: November 25, 2026 • 5 min read

1. Offload Precision Math & Query Boilerplate Into Skills

The biggest takeaway from DeepMind’s 100-compound benchmark is not specific to chemistry: asking an LLM to write bespoke API clients and tolerance calculators on every run guarantees high variance (causing frontier models to miss 25%–33% and Flash to miss over 75%). Wrapping validated community tools inside reusable Antigravity SKILL.md bundles lets fast models like gemini-3.8-flash match frontier models at ~97% accuracy while cutting tokens nearly fourfold.

2. Complete @google/genai v3.x Chemical Tie-Break Example

import { GoogleGenAI } from "@google/genai";

const ai = new GoogleGenAI();

const tieBreak = await ai.interactions.create({
  model: "gemini-3.8-flash",
  thinking_level: "high",
  input:
    "Given SIRIUS formula C20H21ClN6O (-1.5 ppm), complementary fragments m/z 162.1037 and m/z 232.0283, and closed HCl + HNCO neutral-loss loops, rank CID 137835447 (bond-break score 26.0) against CID 55558151 (49.0) and CID 154638626.",
});

console.log(tieBreak.output_text);
