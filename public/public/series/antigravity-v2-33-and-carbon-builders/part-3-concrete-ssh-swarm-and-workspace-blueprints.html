Blueprint 1: Persistent 64-Bit Linux SSH Host Setup

Antigravity v2.33.0 reads your standard ~/.ssh/config and installs its remote server automatically over OpenSSH. Define a host alias targeting your cloud GPU box or build server, then trigger Connect to SSH Host... from the command palette:

# ~/.ssh/config
Host gpu-build-box
  HostName 203.0.113.42
  User builder
  IdentityFile ~/.ssh/id_ed25519
  ServerAliveInterval 60

Once attached, launch a /swarm or long-running build on a Git worktree inside the remote Linux workspace. You can close the Antigravity window while agents execute multi-hour test suites and reconnect later with full terminal and Overview Pull Request state intact.

import { GoogleGenAI } from "@google/genai";

const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });

const interaction = await ai.clients.interactions.create({
  model: "gemini-4-carbon",

});
