⚡ November 17 Afternoon Release Wave

On November 17, 2026, Google shipped Google Antigravity v2.33.0 (16 improvements, 21 fixes) alongside a redesigned Antigravity walkthrough video, Google’s official spotlight on 5 community builds powered by Gemini 4 Carbon, and a DeepMind AlphaGenome & AlphaGenome Atlas briefing detailing how 9 billion single-letter DNA variant predictions accelerate rare disease research.

1. What Changed in Google Antigravity v2.33.0

Surface Previous Baseline (v2.32.x) Antigravity v2.33.0 (Nov 17, 2026)
Remote Compute Local laptop workspaces only for projects, Git worktrees, and agent execution. Connect over SSH to remote 64-bit Linux hosts via ~/.ssh/config; agents & terminals persist after closing the window.
GitHub Pull Requests Raw URL links in chat and artifact cards without live CI/merge telemetry. Live GitHub PR status pills with hover cards, an Overview Pull Requests section, and an optional sidebar indicator.
Enterprise Swarms & Plugins /swarm and UI plugin panels gated away from business/enterprise tiers. Business & enterprise accounts gain /swarm and UI plugin panels (when permitted by org admin) plus Cloudflare, Grafana Cloud, SonarQube, incident.io, Better Stack, Tavily, Levels.fyi, and updated Gemini API plugins.
Browser, Media & Docs 20 MB side-panel media limit; eager PDF text-layer rendering; no browser Cmd/Ctrl+F. 200 MB audio/video playback, .amr voice attachments, deferred PDF text-layer rendering, and built-in browser Cmd/Ctrl+F search.

2. What 5 Builders Built with Gemini 4 Carbon

Writing on the official Google Blog at 21:00 UTC, Kimberly Fusaro documented five real-world builds leaning on Gemini 4 Carbon’s deep exploration and extended verification loops:

  • Wind-Swept Meadow (CUDA & C++): Glitter Gal (@GlitterPixely) synthesized 52,000 wildflowers and grass blades from scratch in CUDA and C++, driving dynamic wind gusts across the field.
  • Million-Particle Tidal Simulation (WebGPU): Chubby (@kimmonismus) simulated 1,048,576 glowing particles swirling in real time inside WebGPU.
  • Fragile Stained-Glass Tower Physics: Andrew V (@AI_Andrew) built a block-stacking game where every piece refracts light, rings acoustically on tap, and shatters into glass shards on collapse.
  • 14 Interactive 3D Public-Record Tools: Giyu_codes (@giyu_codes) turned messy, disorganized public datasets across underserved industries into 14 interactive 3D visual applications.
  • 92-Instrument 19th-Century Optics Lab: Starting from a single reference image, The Bugged Dev (@thebuggeddev) generated an interactive Parisian optics laboratory featuring 92 brass and glass instruments users can test and tune.
