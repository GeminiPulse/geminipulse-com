Release Summary: Antigravity v2.36.0 (Nov 27, 2026)

Shipping 13 improvements and 26 fixes, Google Antigravity v2.36.0 places a floating composer pill with live agent telemetry at the bottom of maximized side panels, expands Auto mode to approve safe edits across other version-controlled repositories and non-replacing file additions, carries spoken context from ended live voice calls into local conversations, adds ~/.agents/skills discovery (with ~/.gemini precedence), and upgrades desktop cloud automation authorization alongside offline MCP OAuth refresh tokens.

1. Keeping Operators in Maximized Context Without Dropping Agent Controls

Developers reviewing a long code diff, an HTML artifact, or a live browser preview in a maximized side panel previously had to un-maximize the pane just to check whether an agent had finished or to fire off a quick follow-up. Antigravity v2.36.0 eliminates that context switch by docking a compact floating composer pill along the bottom edge of maximized side panels.

Even collapsed, the pill renders a live status bar displaying agent progress, unread replies, and saved drafts. Expanding it inline lets you send follow-ups or trigger voice dictation directly on top of the artifact or diff you are inspecting.
