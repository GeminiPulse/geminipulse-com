1. Multi-Repo Sync Without Leaving Maximized Diff Review

Consider a common release pattern: your primary workspace holds the frontend app, while shared schema definitions or documentation live in a sibling Git repository. In v2.36.0, Auto mode lets the agent update that sibling repository without stopping for write approval on every file, while you stay zoomed into the diff viewer and queue follow-ups from the floating composer pill.

2. Layering Shared ~/.agents/skills With Antigravity Overrides

Keep portable cross-agent skills inside ~/.agents/skills/<skill-name>/SKILL.md and place Antigravity-specific overrides (such as Swarm or Workspace-specific guardrails) under ~/.gemini/config/skills/. When names match, Antigravity automatically resolves the ~/.gemini variant first.

Verified v2.36.0 Operator Checklist

  • Keyboard Shortcuts on macOS: Use Option+Cmd+/ to open Keyboard Shortcuts directly (replaces the unreachable ? shortcut).
  • Localhost Browser Testing: Enter localhost:8080 or localhost:3000 in the built-in browser bar without HTTPS rewrite errors.
  • Cloud Automation Auth: Trigger Google sign-in for remote cloud automations directly from the desktop app via your system browser.
  • MCP Offline Refresh: Reconnect any OAuth-protected MCP server once so Antigravity requests offline refresh tokens automatically.
