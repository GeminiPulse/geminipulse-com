1. Expanding Auto Mode Without Weakening Sensitive-Config Guardrails

In v2.35.0, Auto mode began approving out-of-project file reads automatically while guarding sensitive config and session connection directories. Real multi-repo development still hit friction whenever an agent needed to update a sibling repository or write a brand-new additive file outside the active project directory.

v2.36.0 closes that gap safely: Auto mode now auto-approves safe edits inside other version-controlled repositories and non-replacing file additions outside the current project, because Git history or non-destructive file creation remains easy to inspect and revert. At the exact same time, the release patches a legacy-permission bug where allowing non-project file access could previously bypass protections on sensitive configuration files.

2. Deterministic Cross-Tool Skill Discovery

Teams using multiple coding agents often keep shared skills under ~/.agents/skills alongside Antigravity-native skills under ~/.gemini. v2.36.0 scans ~/.agents/skills automatically while enforcing a predictable override hierarchy: if two skills share the same name, the definition inside ~/.gemini takes precedence.
