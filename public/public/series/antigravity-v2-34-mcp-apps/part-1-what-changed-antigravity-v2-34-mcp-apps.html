Release Summary: Antigravity App v2.34.0 (Nov 20, 2026)

Google Antigravity v2.34.0 implements the open MCP Apps specification (io.modelcontextprotocol/ui) with four native rendering surfaces, adds Antigravity-specific entrypoints (com.google.antigravity/ui), ships the built-in /mcp-app-development skill command, and expands Gemini 4 Neon and Orchestrator (Neon + Hydrogen) across paid consumer plans, Gemini API keys, and Application Default Credentials (ADC).

1. Why Plain-Text MCP Outputs Were Ready for a UI Layer

Until Antigravity v2.34.0, Model Context Protocol (MCP) tools connected to live databases, deployment pipelines, and SaaS APIs could only return structured JSON or text payloads back into a linear chat stream. Whenever an engineer wanted to promote a canary rollout, review diff flags, or inspect a custom binary or spatial asset, the user had to leave the agent thread and hunt for an external dashboard.

MCP Apps solve that without breaking existing non-UI clients. An MCP server continues returning standard plain-text content and structuredContent, while attaching a ui:// single-file HTML bundle (text/html;profile=mcp-app) via _meta.ui.resourceUri. Inside the Antigravity desktop App (v2.34.0+), the host renders that interface inside a sandboxed iframe; on Antigravity CLI (agy) and Antigravity IDE extensions, the exact same plugin degrades cleanly to plain-text MCP execution.

2. MCP Apps vs. Generative UI (/generative_ui)

Dimension MCP Apps (v2.34.0+) Generative UI (/generative_ui)
Backing Runtime Live MCP server (local stdio or remote Streamable HTTP) packaged in a plugin Zero-server one-off HTML widget synthesized on the spot by the model
Where It Lives Inline chat cards, side panel (aux_pane), full-page global views, and custom file viewers Single-conversation inline visualization, chart, diagram, or prototype
Bi-Directional Actions Live tools/call, ui/message, ui/update-model-context, and host file reads/writes Ephemeral session UI without a persistent MCP plugin lifecycle
CLI & IDE Fallback Runs the same server as standard plain-text MCP tools automatically Conversation-only visual artifact inside the Antigravity App

3. Gemini 4 Neon, Orchestrator & 15 Workflow Upgrades

Alongside MCP Apps, Antigravity v2.34.0 broadens access to Gemini 4 Neon and Orchestrator (Neon), pairing Gemini 4 Neon as architectural planner with Gemini 4 Hydrogen for high-speed execution. Paid consumer plans, Gemini API key users, Enterprise accounts, and Application Default Credentials (ADC) users can now invoke Neon and Orchestrator directly.

  • Terminal Side Questions (Cmd+E / Ctrl+E): Highlight any error or build output in the integrated terminal and launch an instant side question without breaking your main thread.
  • Cleaner Diffs & Tab References: Diff views adopt a single-column line-number gutter with color-coded change strips, while conversation tabs drag directly from the side panel into the prompt box.
  • Three New Marketplace Plugins: Official partner plugins for Clerk, Docusign, and TestMu AI arrive alongside clickable skill pills that open definitions straight in the side panel, a Thinking effort header tooltip explaining latency vs. quota tradeoffs, and macOS 26 Dark/tinted Dock icon support.
