Concrete MCP App Blueprints, Host Actions & CLI Parity

1. Scaffolding With /mcp-app-development

Inside the Antigravity desktop App, typing /mcp-app-development preloads the built-in MCP Apps skill into the agent's context on turn one. That ensures the agent structures single-file text/html;profile=mcp-app bundles, wires @modelcontextprotocol/ext-apps, configures ${PLUGIN_ROOT} and ${PLUGIN_DATA} inside mcp_config.json, and validates strict plugin packaging via agy plugin validate <path> --strict.

2. Dual-Entrypoint Tool + Isolated File Viewer Declaration

Keep interactive model tools separate from custom file viewers. Any tool carrying a file entrypoint is hidden from the model inside the Antigravity App and receives {"file": {"name", "resourceUri"}} instead of {}, while aux_pane + global tools can be opened both by the agent and manually from the sidebar:

{
  "tools": [
    {
      "name": "open_release_board",
      "_meta": {
        "ui": { "resourceUri": "ui://acme-cloud/deployments.html" },
        "com.google.antigravity/ui": {
          "entrypoints": [
            { "type": "aux_pane", "title": "Acme Deployments" },
            { "type": "global", "title": "Acme Deployments" }
          ]
        }
      }
    },
    {
      "name": "open_topology_file",
      "_meta": {
        "ui": { "resourceUri": "ui://acme-cloud/topology-viewer.html" },
        "com.google.antigravity/ui": {
          "entrypoints": [
            {
              "type": "file",
              "title": "Acme Topology Viewer",
              "extensions": [".acmetopo", ".jsonc"]
            }
          ]
        }
      }
    }
  ]
}

3. Additional Host Actions & agy CLI Fallback

  • Open a File in the Side Panel: Call app.request() with method com.google.antigravity/toggle-aux-pane and params { "tabType": "fileView", "uri": "file:///path/to/file" }, catching JSON-RPC -32601 on non-Antigravity hosts.
  • Launch a Background Thread: Pass _meta: { "com.google.antigravity/message": { "target": "new" } } inside app.sendMessage() (ui/message) to spin up a fresh conversation in the same workspace rather than interrupting the current thread.
  • Respect CLI Plain-Text Parity: Because agy CLI ignores _meta.ui.visibility (exposing app-only helpers and file-viewer tools alike) and renders no iframes, always return concise plain-text content alongside structuredContent and use "command": "node" when relying on Antigravity's bundled Node.js runtime.
