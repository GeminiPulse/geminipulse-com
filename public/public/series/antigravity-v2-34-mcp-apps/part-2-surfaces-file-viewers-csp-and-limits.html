Four Antigravity Surfaces, Custom File Viewers & Strict Host Limits

Authored by Google Gemini 4 Argon · Thinking Effort: High · Product Development & Creative Direction: Neil S. White • Primary Source: Google Antigravity MCP Apps Documentation • 5 min read

1. The Four Entrypoint Surfaces Under com.google.antigravity/ui

During MCP initialize, Antigravity App v2.34.0+ advertises both the open io.modelcontextprotocol/ui capability and com.google.antigravity/ui ({"entrypoints": ["aux_pane", "global", "file"]}). Every tool declares a ui:// HTML resource under _meta.ui.resourceUri and optionally adds Antigravity entrypoints under _meta["com.google.antigravity/ui"].entrypoints:

Surface Metadata Declaration Runtime & Launch Behavior
Inline in chat _meta.ui.resourceUri only Replaces the collapsed MCP tool step card inline; auto-resizes up to 800 px (or falls back to 150 px if no size-changed arrives within 100 ms).
Side panel {"type": "aux_pane", "title"} Auto-opens beside the thread when called by the agent (one tab per (server, tool)). Manual launches from Overview > Plugins or the + menu pass {}; repeat agent calls update the open tab in place.
Full page {"type": "global", "title"} Opens full-width outside any conversation from Plugins in the left sidebar with {}; conversation-only methods (message, updateModelContext) are omitted.
File viewer {"type": "file", "title", "extensions": [".ext"]} Separate host-invoked tool unconditionally hidden from the model regardless of visibility; replaces the built-in viewer for claimed extensions using the plugin logo as tab icon.

2. Opaque Custom File Viewers & Editors (antigravity-file://)

Antigravity protects local filesystem paths when custom viewers open a file. Instead of passing a host disk path, Antigravity invokes the file tool with {"file": {"name": "bracket.stl", "resourceUri": "antigravity-file://<uuid>/bracket.stl"}}. The iframe sends resources/read for that exact opaque URI, and Antigravity responds directly (without hitting your MCP server) with a base64 blob (application/octet-stream, max 10 MiB).

For local editable files, UI code checks hostContext["com.google.antigravity/resources"]?.write before showing save buttons, then sends com.google.antigravity/resources/write with { uri, text } (UTF-8) or { uri, blob } (base64), also capped at 10 MiB.

3. Host Limits, Isolation & Lifecycle Constraints

  • HTML & File Size Ceiling: 10 MiB for bundled ui:// HTML resources and antigravity-file:// reads/writes.
  • Persisted Step Payload: 1 MiB cap on CallToolResult payloads saved on trajectory steps; fetch larger datasets lazily through an app-only tool.
  • Concurrency & Frame Retention: Maximum 4 concurrent tools/call requests per view (aborted on close) and 5 hidden aux_pane / global frames kept in memory (LRU eviction).
  • No Teardown Hook & Default-Deny CSP: Antigravity does not send ui/resource-teardown on close (persist edits eagerly) and enforces a default-deny CSP with no persistent browser storage. Allowlist bare origins only in _meta.ui.csp, and prefer tools/call over connectDomains.
