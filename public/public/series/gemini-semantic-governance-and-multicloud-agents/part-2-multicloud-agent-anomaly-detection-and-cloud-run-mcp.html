1. Auditing External Agents on AWS Lambda, Amazon Bedrock & Microsoft Foundry

Because Agent Anomaly Detection evaluates telemetry traces and conversation log events out of band, it does not need network access to your agent runtime. On November 20, 2026, Google opened Private Preview support for external agents built with Agent Development Kit (ADK) for Python v2.12.0+ using keyless Workload Identity Federation (exchanging AWS IAM roles or Microsoft Entra identities for short-lived Google credentials) and OpenTelemetry export to telemetry.googleapis.com.

GOOGLE_CLOUD_PROJECT=PROJECT_ID
GOOGLE_APPLICATION_CREDENTIALS=/path/to/gcp-workload-identity-config.json
OTEL_SEMCONV_STABILITY_OPT_IN=gen_ai_latest_experimental
OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT=EVENT_ONLY
ADK_CAPTURE_MESSAGE_CONTENT_IN_SPANS=false
OTEL_SERVICE_NAME=inventory-agent
OTEL_RESOURCE_ATTRIBUTES=cloud.provider=aws,cloud.platform=aws_lambda,cloud.region=us-east-1,faas.name=inventory-agent

Within 30 minutes of telemetry arrival, the external agent appears under Monitored agents. In Google’s multi-cloud tests, the detector flagged 10 of 40 Amazon Nova Lite Bedrock sessions that paged through an entire product catalog until timing out (cascading failures and resource exhaustion), and caught all 4 of 6 adversarial Microsoft Foundry sessions—including a spoofed store administrator extracting $1,784.90 in 10x refunds to a personal account and a pasted SYSTEM OVERRIDE order note triggering a $999 refund on a $15.99 order.
