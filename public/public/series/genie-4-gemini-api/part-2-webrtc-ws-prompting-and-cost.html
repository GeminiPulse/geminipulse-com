1. Four-Step Session Lifecycle & Transport Tradeoffs

Every models/genie-4 integration follows one strict four-step pattern: (1) create the interaction server-side (and mint an auth_tokens/... ephemeral token for browsers), (2) connect via WebRTC (browsers) or WebSocket (Python, Node.js, or headless RL loops), (3) emit one world_setup event followed by user_action key/camera controls and mid-session text inputs, and (4) terminate billing cleanly with await session.complete().

  • WebRTC Reference Image Budget: Browser SCTP data channels cap JSON payloads at 64 KB. Keep compressed 16:9 JPEG seed images under 48 KB so base64 encoding does not exceed the WebRTC frame limit.
  • Mid-Session Impulse Pattern: Custom action bindings (such as E, Q, R) are not hardcoded by the model; clients send mid-session text impulses repeated 10x at 150 ms intervals with a 2-second cooldown so the next world step reliably picks up the event.
  • Initial Frame Warmup & Session Drift: Expect ~5–9 seconds before frame 1 arrives after world_setup. Camera and keyboard steering respond in ~0.2–0.5s, while mid-session text shifts settle in ~1–2s. Visual coherence is strongest during the first 45–90 seconds up to the hard 120-second session ceiling.

2. Five Tested Genie 4 Prompting Rules (Why Movie-Trailer Prompts Fail)

Google’s engineering guide warns that cinematic phrasing like "upbeat synth soundtrack" or "quick cuts to an aerial drone shot" breaks a live 24 fps camera stream: soundtrack words turn into physical in-world Foley noises, and camera cuts fracture spatial continuity.

  • Causal Object Rules ("Chekhov’s Lever"): Embed triggers as Rule: Pulling the red lever... bound to a physical object or character rather than an abstract room boundary, place the trigger "far away from me" so it does not misfire at frame 1, and instruct NPCs with "who waits until a rule is triggered".
  • Key-Bound Action Verbs: Pair walk-first exploration with explicit E / Q / R action bindings whenever deterministic button triggers matter more than probabilistic world triggers.
  • Quoted Spoken Dialogue: Wrap mid-session character speech in quotation marks ("\"What wine would you recommend?\"") to trigger direct NPC voice replies inside the 48 kHz audio stream.
