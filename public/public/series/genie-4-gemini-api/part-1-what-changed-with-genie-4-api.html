What Changed With Genie 4 on the Gemini API: Real-Time World Streams Open to Developers

Authored by Google Gemini 4 Argon · Thinking Effort: High · Product Development & Creative Direction: Neil S. White • Published November 19, 2026 • Primary Sources: Google Blog: Genie 4 on the Gemini API, Gemini API Genie 4 Docs & Changelog • 7 min read

Release Summary: November 19, 2026 (17:00 UTC)

Twenty-four hours after launching Genie 4 for Google AI Ultra consumers in Project Genie, Google made models/genie-4 generally available to paid-tier developers via the Gemini API Interactions API (v1beta) and Google AI Studio. Developers can now stream steerable 1280x720 (16:9) video at 24 fps with synchronized 48 kHz stereo audio over WebRTC and WebSockets at $1.50 input / $9.00 text output / $17.50 video output per 1M tokens (~$0.10/sec).

1. From Consumer Web App to Programmable World Stream

Until November 19, 2026, experiencing Genie 4 required a Google AI Ultra subscription inside the Project Genie web interface. Builders, game prototypers, spatial designers, and robotics teams could not embed a live world session inside their own React apps, Python simulation harnesses, or custom hardware controllers.

Today’s release exposes models/genie-4 directly through the official @google/genai (TypeScript/JavaScript) and google-genai (Python) SDKs—complete with server-minted ephemeral browser tokens (interactions.authTokens.create()) so production web apps never leak a long-lived GEMINI_API_KEY.

3. Key Architectural Boundaries Developers Need to Know Day One

  • Uses Interactions API (v1beta), Not Live API: Genie 4 runs via interactions.create() and interactions.connect(). It does not support the standard Live API, Batch API, Flex inference, Priority inference, Context Caching, Function Calling, Search Grounding, or Free Tier keys.
  • Billing Continues Until session.complete(): Each frame consumes 240 video output tokens (5,760 tokens/sec at 24 fps). Closing a browser tab detaches the WebRTC transport without immediately halting server generation, so clients must explicitly call await session.complete() (and Google AI Studio enforces a 10-second background-tab pause).
  • US-Only Serving Latency Constraint: Genie 4 currently serves exclusively from US data centers; round-trip network latency above 150 ms noticeably degrades reflex steering, making North American backend relays recommended for interactive products.
