Blueprint 1: Real-Time Multimodal Live Session with proactiveVideo (TypeScript)

This implementation connects to the Gemini Live API via WebSocket using @google/genai@^3.1.0, enables proactiveVideo inside proactivityConfig, and sets up a throttled 1fps camera ingestion loop.

import { GoogleGenAI } from '@google/genai';

// Initialize SDK v3.1.0 (defaults to stable v1 API)
const ai = new GoogleGenAI({
  apiKey: process.env.GEMINI_API_KEY,
});

async function runProactiveVisionSession() {
  // Establish bidirectional Live API connection
  const session = await ai.live.connect({
    model: 'gemini-3.8-flash',
    config: {
      generationConfig: {
        responseModalities: ['AUDIO'],
        speechConfig: {
          voiceConfig: {
            prebuiltVoiceConfig: { voiceName: 'Puck' }
          }
        }
      },
      // SDK v3.1.0: Enable autonomous vision triggers
      proactivityConfig: {
        proactiveAudio: true, // Required for proactiveVideo
        proactiveVideo: true, // Triggers autonomous model turns on visual deltas
      },
      systemInstruction: {
        parts: [{
          text: `You are an ambient industrial assembly sentinel.
Observe the video stream silently. Do NOT narrate routine steps.
ONLY speak up immediately if the technician attaches the wrong wire or leaves a screw loose.`
        }]
      }
    }
  });

  console.log('✅ Live Proactive Session Established');

  // Handle incoming autonomous speech / server events
  session.on('content', (content) => {
    if (content.modelTurn?.parts) {
      for (const part of content.modelTurn.parts) {
        if (part.inlineData?.mimeType?.startsWith('audio/')) {
          playAudioPCM(part.inlineData.data);
        } else if (part.text) {
          console.log('🗣️ Autonomous Agent Alert:', part.text);
        }
      }
    }
  });

  // Client-side frame streaming throttled to 1 fps to manage token burn
  const camera = getCameraCaptureStream();
  setInterval(async () => {
    const jpegFrameBase64 = await camera.captureFrameJpeg({ quality: 0.8, maxWidth: 768 });
    await session.sendRealtimeInput({
      mediaChunks: [{
        mimeType: 'image/jpeg',
        data: jpegFrameBase64
      }]
    });
  }, 1000); // 1 frame/sec = ~258 tokens/sec (~15.5K tokens/min)
}

Blueprint 2: High-Reasoning Escalation with gemini-4-carbon (Python)

Using google-genai>=3.1.0, this blueprint invokes the newly typed gemini-4-carbon model inside the Interactions API for deep reasoning tasks, complete with tunable thinking levels.

import os
from google import genai
from google.genai import types

# Initialize client using Google GenAI SDK v3.1.0
client = genai.Client(api_key=os.environ.get("GEMINI_API_KEY"))

def verify_structural_anomaly(anomaly_telemetry: str, image_bytes: bytes) -> str:
    """Escalates frontline vision findings to Gemini 4 Carbon for formal verification."""
    
    # In SDK v3.1.0, 'gemini-4-carbon' is strictly typed in the Model enum
    response = client.interactions.create(
        model=types.Model.GEMINI_4_CARBON,
        input=[
            types.Content(
                parts=[
                    types.Part.from_bytes(data=image_bytes, mime_type="image/jpeg"),
                    types.Part.from_text(
                        text=f"Formal engineering assessment required for anomaly: {anomaly_telemetry}. "
                             f"Verify against ASME Section VIII Division 1 guidelines and provide formal mathematical bounds."
                    )
                ]
            )
        ],
        thinking_config=types.ThinkingConfig(
            thinking_level=types.ThinkingLevel.HIGH  # Max reasoning budget for frontier verification
        )
    )

    print(f"Verified by Carbon (Thoughts: {response.usage_metadata.thoughts_token_count} tokens)")
    return response.output_text

Blueprint 3: Automated Video Ingestion with gemini-omni-1.2-flash

In SDK v3.1.0, gemini-omni-1.2-flash is the default video engine. You can invoke it via CLI or programmatic script to extract frame-accurate chapters and audio-visual correlation:

# 1. CLI Execution (SDK v3.1.0 defaults to gemini-omni-1.2-flash automatically):
gemini-api video analyze ./site_inspection_4k.mp4 \
  --prompt "Generate chapter timestamps with ISO 8601 bounding boxes for any safety violations."

# 2. Programmatic Python SDK Ingestion:
from google import genai
from google.genai import types

client = genai.Client()

# Upload video file to File API
video_file = client.files.upload(file="./site_inspection_4k.mp4")

# Analyze using default Omni 1.2 Flash
response = client.models.generate_content(
    model="gemini-omni-1.2-flash",
    contents=[
        video_file,
        "Identify every moment where protective gear was removed. Format as JSON with [start, end, bbox]."
    ],
    config=types.GenerateContentConfig(
        response_mime_type="application/json"
    )
)

print(response.text)

Blueprint 4: Enterprise Embedding with Truncation Telemetry (TypeScript)

SDK v3.1.0 exposes truncated and usageMetadata.trafficType on EmbedContentResponse, allowing RAG pipelines to guard against silent data clipping:

import { GoogleGenAI } from '@google/genai';

const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });

async function embedKnowledgeDocument(documentText: string) {
  const response = await ai.models.embedContent({
    model: 'text-embedding-005',
    contents: documentText,
  });

  // SDK v3.1.0 Telemetry fields:
  if (response.truncated) {
    console.warn('⚠️ WARNING: Document exceeded context limit and was truncated before vectorization!');
  }

  if (response.usageMetadata?.trafficType) {
    console.log(`📊 Processing Tier: ${response.usageMetadata.trafficType}`);
  }

  return response.embedding.values;
}
