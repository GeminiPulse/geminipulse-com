Global Endpoint Routing, Polling Lifecycle & ADK Per-Run Configuration

Authored by Google Gemini 4 Argon · Thinking Effort: High · Product Development & Creative Direction: Neil S. White • Published November 20, 2026 • Primary Sources: Deferred Tier Guide & ADK Deferred Scheduling Docs • 5 min read

1. Non-Negotiable Request Contract on interactions.create

Because the scheduler pulls capacity from a worldwide pool, Deferred Tier operates exclusively on locations/global at aiplatform.googleapis.com. Routing a deferred request to us, eu, or any single region returns HTTP 400 invalid_request. Every creation call must also set service_tier: "deferred", background: true, and store: true, while omitting stream: true on initial creation.

Once interactions.get reports status: "in_progress", clients can optionally attach an SSE stream via stream: true and resume dropped connections using last_event_id. Note that turn-scoped settings such as tools, system_instruction, and generation_config do not carry across turns automatically and must be re-sent on each chained previous_interaction_id call.

2. Interaction Status Lifecycle & Billing State Machine

Status Value Final? Required Client Action
queued No Accepted and waiting for off-peak global capacity. Poll interactions.get with exponential backoff (up to 30s intervals); do not pass stream=true yet.
in_progress No Actively decoding. Continue polling interactions.get or attach an SSE stream with stream=true and last_event_id.
requires_action Yes Model emitted a function_call step. Execute the tool locally and submit the tool result in a new turn referencing previous_interaction_id.
requires_continuation Yes Long decode paused with a continuation_token. Resume with previous_interaction_id + continuation_token, omit input, and raise max_output_tokens.
completed Yes Turn succeeded at 50% PayGo pricing. Read output_text and usage, or chain the next step within the 7-day state window.
failed / cancelled / expired Yes Zero token charges incurred. Cancel only while queued or in_progress (cancelling a final turn returns HTTP 409 aborted).

3. ADK Per-Run Toggle & Enterprise Security Boundaries

In ADK Python v2.10.0+, deferred scheduling lives inside RunConfig(service_tier=ServiceTier.DEFERRED) rather than on the agent definition itself. Provided the model uses Gemini(..., use_interactions_api=True), one deployed agent can handle real-time user requests interactively and run overnight batch loops at half price without maintaining two agent codebases. Note that run_async() yields no events while waiting in the queue, so headless workers should set explicit client deadlines or show progress state.

On the security front, Google Cloud supports VPC Service Controls (external mcp_server tools are disallowed inside a VPC-SC perimeter), Access Transparency, Cloud Audit Logs, and FedRAMP High. However, stateless zero data retention (store=false or constraints/vertexai.disableAPIStorage), CMEK, Data residency, DoD IL5, and ITAR are not supported on the Deferred tier.
