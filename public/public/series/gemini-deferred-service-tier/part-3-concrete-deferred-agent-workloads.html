1. Three Workloads Where Deferred Tier Cuts Costs by 50% Immediately

  • Overnight Repository Vulnerability & Migration Agents: Schedule gemini-4-carbon or gemini-4-neon sweeps across pull-request diffs, test failures, and dependency advisories without fighting daytime interactive quotas. Keep uncompressed request bodies under 9.75 MiB and pass large artifacts as gs:// URIs (up to 100 per chain, backed by roles/storage.objectViewer).
  • Multi-Document Synthesis & Financial Backtesting: Combine gemini-4-argon tool loops with previous_interaction_id chaining so agents query filing tables, compare quarterly transcripts, and write auditable memos while retaining 7-day interaction history.
  • Large-Scale Offline Agent Benchmarks: Run 1,000+ multi-turn evaluation trajectories across candidate prompts or model checkpoints overnight, absorbing transient rate spikes with server-side queuing and zero charges on expired or cancelled runs.

2. Production Polling & Multi-Turn Chaining Snippet (@google/genai)

import { GoogleGenAI } from "@google/genai";

const ai = new GoogleGenAI({
  enterprise: true,
  project: process.env.GOOGLE_CLOUD_PROJECT,
  location: "global", // Required: regional or us/eu endpoints return HTTP 400
});

const turnOne = await ai.interactions.create({
  model: "gemini-4-argon",
  input: "Audit auth middleware in gs://repo-snapshots/pr-412.tar.gz for token replay flaws.",
  service_tier: "deferred",
  background: true,
  store: true,
});

// Poll interactions.get until status leaves "queued" or "in_progress",
// then chain turnTwo via previous_interaction_id (re-send tools & system_instruction).
const turnTwo = await ai.interactions.create({
  model: "gemini-4-argon",
  previous_interaction_id: turnOne.id,
  input: "Generate patch verification checklist for each critical finding.",
  service_tier: "deferred",
  background: true,
  store: true,
});
