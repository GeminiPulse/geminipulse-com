Use Case 2: Long-Decode Migration Specs & Full Test Suites (>64K Tokens)

Who benefits: Enterprise modernization teams generating complete multi-module specifications, OpenAPI contracts, and end-to-end test suites in a single coherent pass.

Pattern: Combine background: true with max_output_tokens: 262144 (up to Neon’s 1,048,576 unified context ceiling) so server-side 64K-token continuation hops assemble a complete deliverable without truncation:

import time
from google import genai

# google-genai v3.6.1 supports "gemini-4-neon" natively
client = genai.Client()
interaction = client.interactions.create(
    model="gemini-4-neon",
    input="Generate a complete multi-module migration specification and test suite for this service.",
    background=True,
    generation_config={
        "max_output_tokens": 262144,
        "thinking_level": "high",
    },
)

while interaction.status in ("in_progress", "queued"):
    time.sleep(5)
    interaction = client.interactions.get(id=interaction.id)

text = "".join(
    content.text
    for step in interaction.steps
    if step.type == "model_output"
    for content in step.content
    if content.type == "text"
)
print(text)
