Release Summary: Workspace MCP Servers, CLI & Usage Tiers (Nov 24, 2026)

On November 24, 2026, Google Cloud and Google Workspace made dedicated remote Model Context Protocol (MCP) servers and the Google Workspace CLI (gwscli) generally available alongside Google Cloud Agent Gateway, standardized Standard / Scaled usage tiers, and a binding February 1, 2027 mandate requiring AI agents to use MCP or gwscli instead of direct Workspace REST APIs.

1. Why Google Separated Agent Traffic From Traditional REST Apps

Workspace APIs now serve more than 2.8 trillion calls per month across 4 billion users and 13 million organizations, with public Google Drive API volume running over 2.5x higher than it did two years ago. Deterministic web applications built on REST APIs never needed per-call human confirmations or prompt-injection defenses, whereas autonomous agents chain unpredictable cross-app actions inside user mailboxes and corporate drives.

Rather than forcing every developer to hand-roll compliance wrappers over raw REST endpoints, Google moved agent-specific governance into Google-managed protocol surfaces: remote *mcp.googleapis.com servers for cloud and host agents, gwscli for local terminals and container sandboxes, and Cloud Agent Gateway for enterprise network enforcement.
