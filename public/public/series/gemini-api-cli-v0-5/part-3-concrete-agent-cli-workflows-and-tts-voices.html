Three Concrete Production Workflows for Gemini API CLI v0.5.0

Authored by Google Gemini 4 Argon · Thinking Effort: High · Product Development & Creative Direction: Neil S. White • Published November 20, 2026 • Primary Source: google-gemini/gemini-api-cli v0.5.0 • 5 min read

1. Host Agent Asset & Research Pipeline (--agent-mode + --dry-run)

Drop the official instruction snippet into AGENTS.md or CLAUDE.md so coding agents generate hero imagery with gemini-nano-banana-2.1, launch background Deep Research runs (--agent deep-research-preview-04-2026 --background), and validate payloads via --dry-run --output-format json before spending tokens.

# 1. Validate request without hitting the network or OS keychain
gemini-api image --body @hero-image.json --out ./assets/hero.jpg --dry-run --output-format json

# 2. Kick off background managed agent and capture interaction ID
INTERACTION_ID=$(gemini-api agent run "Audit WebRTC SCTP payload caps" \
  --agent deep-research-preview-04-2026 --background --jq '.id')

2. Custom Voice Design & Normalized Narration (voices + tts --style)

Version 0.5.0 onboards the voices subcommand group (create, list, get, delete) and exposes --style, --voice-prompt, and SpeechConfig.text_normalization so build scripts verbalize SKUs, dates, and release numbers cleanly with gemini-3.8-flash-tts.

# List custom and built-in voices, then synthesize styled narration
gemini-api voices list --all --output-format toon
gemini-api tts "Release v0.5.0 ships November 20, 2026 at 00:49 UTC." \
  --style "Crisp studio engineering briefing" \
  --out ./audio/release-brief.wav

3. Self-Hosted BYOS Sandbox Dispatch (antigravity-preview-09-2026)

Create a self_hosted environment with per-environment variables (CreateEnvironmentRequest.env), deploy a Cloudflare Sandbox Container or rootless Podman worker running gemini-api environments connect, and invoke remote Interactions turns confined to your private VPC filesystem.
