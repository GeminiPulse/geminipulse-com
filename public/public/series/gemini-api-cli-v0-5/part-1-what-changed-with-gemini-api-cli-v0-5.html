What Changed in Gemini API CLI v0.5.0: One Stateless Go Binary for Models, Media & Managed Agents

Authored by Google Gemini 4 Argon · Thinking Effort: High · Product Development & Creative Direction: Neil S. White • Published November 20, 2026 • Primary Source: google-gemini/gemini-api-cli v0.5.0 • 6 min read

Release Summary: November 20, 2026 (00:49 UTC)

Google shipped google-gemini/gemini-api-cli v0.5.0 (Apache 2.0 single Go binary for macOS, Linux, and Windows). The release promotes gemini-4-hydrogen to the default model, adds gemini-4-carbon, gemini-omni-1.2-flash, and XHIGH / xhigh thinking levels, introduces self-hosted BYOS environments mode with split poller/worker lease tokens, wires Tool Retrieval schemas, and onboards the voices command group alongside expressive TTS controls.

1. Why Google Built a Separate CLI Alongside gemini-cli

Unlike google-gemini/gemini-cli, which acts as an interactive terminal coding agent with its own conversation loop, gemini-api is intentionally stateless and agent-agnostic. It gives any coding agent with shell access—Google Antigravity, Claude Code, Codex, OpenClaw, Hermes, or CI pipelines—immediate access to Gemini models, media generation, file analysis, and background managed agents without maintaining custom Python or TypeScript glue scripts.

3. Machine-First Ergonomics: TOON, --schema, and Redacted --dry-run

  • Compact TOON Output (--agent-mode): Setting --agent-mode or GEMINI_CLI_AGENT_MODE=1 routes structured JSON error envelopes to stderr and compact Token-Oriented Object Notation (TOON) to stdout, trimming token waste when a host agent inspects CLI responses.
  • Self-Describing Request Schemas: Running gemini-api image --schema or gemini-api agent run --schema dumps the exact Interactions API JSON schema so host agents inspect capabilities at runtime and pass custom payloads via --body @payload.json.
  • Zero-Network Credential-Safe Validation: Passing --dry-run validates parameters locally and prints the resolved HTTP request with credentials redacted—without touching the OS keychain or making an API request.
