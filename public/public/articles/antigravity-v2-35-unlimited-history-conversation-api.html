PART I · α CASTOR · OPERATOR MEMORY, PERMISSIONS & WORKSPACE ERGONOMICS LENS α CASTOR · THE SIGNAL

Why Conversation Lifecycle Control Matters as Much as Model Intelligence

Turning ephemeral chat tabs into a permanent, taggable, scriptable engineering ledger that survives across projects, remote SSH hosts, and automated swarms.

As autonomous coding tools shifted from single-question assistants into continuous background workers, a quiet operational bottleneck emerged: thread sprawl. Once an engineering team pairs scheduled automations with parallel subagent swarms, five hundred local conversations fill up fast, quietly evicting the exact architecture debate or debugging trace someone needs a month later.

In Google Antigravity v2.35.0 (released November 23, 2026 with 20 improvements and 19 fixes), that silent pruning cap disappears. Local conversation history is now unlimited by default, ensuring prior decisions, diffs, and side-question matches stay intact on disk. Even better, conversations are no longer passive UI rows: the built-in Conversation Management API and conversations skill let agents, scripts, plugins, and automations programmatically create, list, inspect, rename, pin, star, archive, tag, group, and delete threads.

Every other workflow change in v2.35.0 targets the daily friction operators actually hit when steering multiple agents at once. Full-page HTML artifacts now support native Cmd+F (or Ctrl+F on Windows and Linux) match highlighting and navigation. Markdown and plain-text tabs gain per-tab RTL toggles without flipping code blocks. The message composer moves the Environment selector ahead of Project and Branch—putting SSH hosts directly up front—while locking model and permission selectors mid-turn with explanatory tooltips so users never mistakenly think a dropdown flip changed an active turn.

For security-conscious teams and Marketplace builders, Auto permission mode now approves file reads outside the active workspace automatically (while protecting sensitive configuration directories) and suggests broader directory scopes rather than repetitive single-file prompts on external writes. Meanwhile, ClickUp, Midpage Legal Research, and Descrybe Legal Engine join the Marketplace, and the official Gemini API Marketplace plugin updates to v2.8.0 with Gemini 4 Neon usage and migration guidance.

“When agents can tag, group, pin, and inspect their own local conversation histories without hitting a 500-thread cliff, chat threads finally behave like durable software infrastructure.”

CHAPTER 02 / 04 · WHAT THIS MEANS FOR YOU ADAPTIVE READER QUESTIONS
FOR ENGINEERING MANAGERS & SOLO FOUNDERS

Why did Antigravity change default Orchestrator and Executor thinking effort from Extra High to High?

High thinking effort hits the sweet spot between latency, token quota, and reliability across Gemini 4 Neon, Carbon, and Hydrogen, while leaving Extra High (xhigh) available manually whenever deep deductive audits warrant longer turn times.

FOR AUTOMATION & WORKFLOW BUILDERS

What can the new Conversation Management API and conversations skill automate?

Scripts, plugins, scheduled automations, and agents can create, list, inspect, rename, pin, star, archive, tag, group, and delete local Antigravity conversations—enabling automated morning inbox tagging, release audit grouping, or cross-thread handoffs.

FOR SECURITY & COMPLIANCE TEAMS

Does Auto permission mode expose credentials outside the current workspace?

No. While Auto mode now approves routine file reads outside the active project directory to reduce prompt fatigue, Antigravity explicitly keeps sensitive configuration directories protected and also patched internal session-connection file isolation in v2.35.0.

PART II · β POLLUX · CONVERSATION LIFECYCLE, SWARM PAGING & PERMISSION BOUNDARIES LENS β POLLUX · THE WORKBENCH

Under the Hood of Antigravity v2.35.0: Paged Swarms, API Hygiene & 19 Edge-Case Fixes

How on-demand Swarm paging, directory-scoped permission patterns, High thinking defaults, and queue delivery diagnostics eliminate silent multi-agent friction.

Three architectural refinements in Antigravity v2.35.0 directly fix failure modes that only surface once you run long-lived autonomous workspaces. First, the Swarm board replaces eager history hydration with on-demand message paging, incremental board diffs, and throttled polling when the Swarm pane is hidden—paired with UI collapsing for consecutive parallel subagent launches and automatic merging of adjacent Worked for sections with no intervening output.

Second, queue and side-question state transitions are significantly safer. The queued messages card now names the exact active background tasks or subagents holding delivery after a turn ends so you can wait or click Send Now deliberately. Nineteen targeted fixes patch subtle race conditions where pressing Stop could drop a just-sent follow-up, Send Now could overwrite message drafts, splitting a terminal lost scroll and focus, or dollar signs inside shell commands triggered accidental math-formula rendering.

Third, sandbox and enterprise account hygiene tighten alongside usability. Auto-mode safety checks now evaluate commands against the true working directory, file tools and sandboxed commands are blocked from reading internal session connection files, enterprise sign-ins refresh revoked account states cleanly, and the official Gemini API Marketplace plugin v2.8.0 brings up-to-date Gemini 4 Neon and @google/genai v3.x migration instructions directly inside the workspace.
