December-Proofing Your Carbon Stack with Explicit Caching & Long Decode

How to hold effective input spend near $0.20/1M even after the December 1 rate step-up.

Let’s do the exact token math for December 1 so your architecture never flinches. Suppose your security or financial analysis agent repeatedly queries a 500,000-token repository or dataroom across 40 turns. If you re-send 500K uncached tokens 40 times at December’s $4.00/1M rate, you burn 20M input tokens = $80.00. If instead you pin that 500K dataroom in a 95%-discounted Context Cache (ai.caches.create), you pay the base write once and pay $0.20/1M (just $0.10/1M through Nov 30!) on all 39 follow-up reads—slashing the exact same 40-turn session down to ~$5.90.

Second, take full advantage of Carbon’s tunable thinking_level ("low", "medium", "high") per turn. Even inside a Carbon session, follow-up formatting or diff extraction turns do not need "high" reasoning depth—dropping follow-up turns to "low" or handing worker implementation off to gemini-4-hydrogen ($7.50/1M output vs. Carbon’s Dec 1 $20.00/1M) keeps total task cost more than 2x below rival frontier stacks.

Finally, when emitting >64K-token outputs via Long Decode, always use the @google/genai v3.x Interactions API (ai.interactions.create) with automatic_continuation: true so multi-segment generation stitches seamlessly without brittle manual cursor loops.

import { GoogleGenAI, ThinkingLevel } from "@google/genai";

const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });

export async function runCachedCarbonSecuritySuite({ fullRepoBundle, auditPasses }) {
  // 1. Pin 100K–900K repo bundle once to unlock the 95% cached input discount
  const repoCache = await ai.caches.create({
    model: "gemini-4-carbon",
    config: {
      displayName: "repo-security-snapshot",
      contents: [{ role: "user", parts: [{ text: fullRepoBundle }] }],
      ttl: "3600s",
    },
  });

  // 2. Run multiple specialized Carbon passes at 95%-off cached input + Long Decode
  const findings = [];
  for (const passPrompt of auditPasses) {
    const interaction = await ai.interactions.create({
      model: "gemini-4-carbon",
      input: passPrompt,
      config: {
        cached_content: repoCache.name,
        thinking_config: { thinking_level: ThinkingLevel.HIGH },
        automatic_continuation: true, // Seamless >64K Long Decode
      },
    });
    findings.push({
      passPrompt,
      report: interaction.output_text,
      usage: interaction.usageMetadata,
    });
  }

  return { cacheName: repoCache.name, findings };
}
