# Gemini (T)winning Starter Kit (`gemini-twin-starter`)

Free, open-source **Google Antigravity** community plugin published by **[GeminiPulse.com](https://geminipulse.com/#addons)**.

Built for everyone on their road to **(t)winning** with Google Gemini—from everyday **"Joes & Jills"** mastering Google Workspace & NotebookLM, to WordPress webmasters *"mAiking the swAitch"* to `$0/mo` Firebase Hosting, to **"Pros"** shipping with the Google GenAI Interactions API.

## What's Inside
- **Agent (`twin-coach`):** Plain-English Rosetta Stone mentor subagent translating WordPress/FTP/MySQL/Excel habits into Google Antigravity, Cloud Firestore, AI Studio & Google Workspace.
- **Skill (`google-suite-power-prompts`):** 5 high-ROI daily Gemini workflows for Gmail, Docs, Sheets, Slides & NotebookLM.
- **Skill (`interactions-api-quickstart`):** Copy-paste `@google/genai` v2.32+ (TS) & `google-genai` v2.34+ (Python) `client.interactions.create()` templates with Search Grounding and `automatic_continuation`.
- **Skill (`antigravity-token-diet`):** The 20,000-token Customization Budget hygiene checklist to cut static token overhead by 30–40%.

## 1-Line Install into Google Antigravity
```bash
curl -fsSL https://geminipulse.com/downloads/install-gemini-twin-starter.sh | bash
```
*(Restart Google Antigravity once after installing a new plugin directory so the runtime indexes `gemini-twin-starter`.)*
